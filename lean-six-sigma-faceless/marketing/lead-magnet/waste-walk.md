# The 60-Minute Waste Walk

**Type:** Guided audit + worksheet
**For:** An owner or manager of a small business where the same job runs many times a
week and comes out differently every time.
**Problem it solves:** You know something is wrong with how a job runs. You cannot say
precisely what, or what it costs, so you cannot fix it.

**What you need:** one hour, a pen, this worksheet, and permission to interrupt the
person who actually does the job.

> This is the complete lead magnet content. It works on its own. If you never buy
> anything from us, you should still finish this hour with a ranked list and a
> decision.

---

## Before you start: three rules

**1. Watch the work, not the plan.**
You are recording what *actually* happens, including the workarounds. The gap between
the plan and the reality is where the money is.

**2. Say out loud that this is not about anyone's job.**
Say it before you start, to whoever you are watching. The moment someone thinks they
are being timed for a performance review, you stop getting the truth — and the truth
is the only thing this hour produces. This is the single most common reason
improvement efforts fail in small businesses.

**3. One process. The annoying one.**
Not the department. Not the business. One process, with a clear start and a clear
finish. If you cannot say where it starts and stops, it is too big — pick a piece.

---

## Step 1 — Name the process (5 minutes)

Write one sentence:

> "This process starts when ______________ and finishes when ______________."

**Examples:**
- Starts when a customer calls to book, finishes when the job is in the diary and confirmed.
- Starts when the van is loaded, finishes when the job sheet comes back to the office.
- Starts when an order drops, finishes when it is packed and labelled.

**Then answer:**
- How many times does this run per week? `______`
- Roughly how long should it take? `______`
- When it goes wrong, what happens? `_______________________`
- How often does it go wrong? `______ in 10`

> **If you cannot answer "how often does it go wrong" — that is your first finding.**
> You are running a process whose failure rate is invisible to you. Write down
> "unknown" and keep going; you will fix that in Step 5.

---

## Step 2 — Walk it (20 minutes)

Go to where the work happens. Watch one real run of it — or if it takes days, walk the
path it takes and talk to each person who touches it.

Write down **every step**, in order, as it actually happens. Aim for 8–15 lines. If
you are past 20, your process is too big — cut it down and come back.

| # | What happens | Who | Roughly how long | Waiting before this step? |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |
| … | | | | |

**Ask the person doing it three questions:**

1. "What is the annoying part of this?"
2. "What do you do when it goes wrong?"
3. "Is there anything you do that you think is a waste of time?"

Write their answers down verbatim. Do not defend anything, do not fix anything, and
do not explain why it is like that. You are collecting, not solving.

> Almost everyone tries to fix things during the walk. Resist it for twenty minutes.
> The first fix you think of is usually aimed at a symptom.

---

## Step 3 — Mark where it leaks (15 minutes)

Go back through your list. Against each step, mark every letter that applies. Most
steps get none. Some get three.

| Mark | What it means | What it looks like in a small business |
|---|---|---|
| **W** | Waiting | Sat in someone's inbox. Waiting on a decision, a part, an approval, a callback. |
| **R** | Rework | Doing it again because it was wrong the first time. Callbacks. Re-quotes. |
| **M** | Motion | Walking, driving, hunting for something. The second trip to the van. |
| **T** | Transport | Moving the job or the paperwork between people or places for no reason. |
| **E** | Extra | Doing more than the customer asked for or needs. Fields nobody reads. |
| **D** | Double entry | Typing the same information into a second place. |
| **K** | Knowledge | Only one person can do this step, or knows this answer. |

> **The W and K columns are usually where the shock is.** In most small businesses the
> work takes an hour and the *process* takes three days, and almost all of the
> difference is waiting. K is the one that keeps owners awake — every K is a step that
> stops when that person is on holiday.

**Now total them:**

| Mark | Count | Steps |
|---|---|---|
| W — waiting | | |
| R — rework | | |
| M — motion | | |
| T — transport | | |
| E — extra | | |
| D — double entry | | |
| K — knowledge | | |

## Step 4 — Put a number on it (10 minutes)

Rough is fine. You are ranking, not doing accounts. A wrong estimate you can improve
beats an exact number you never worked out.

Pick your worst three marks and fill in:

| Problem (step + mark) | Times per week | Minutes lost each time | Minutes/week | ×52 ÷60 = hours/year |
|---|---|---|---|---|
| | | | | |
| | | | | |
| | | | | |

**And for anything marked R (rework), also ask:** what does one instance cost in
materials, in a wasted visit, or in a lost customer? Rework is usually the most
expensive thing on the sheet and the easiest to underestimate, because the first
attempt has already been paid for.

> **A caution about the annual number.** Multiplying by 52 makes it look enormous, and
> the enormous number is not money you can go and collect — some of that time will
> just become slack. Use it to *rank* problems against each other, not to forecast
> savings. Anyone who tells you that hours-per-year converts straight into cash is
> selling something.

---

## Step 5 — Decide one thing (10 minutes)

**Your ranked list:**

1. `_________________________________` — costs roughly `______` hrs/year
2. `_________________________________` — costs roughly `______` hrs/year
3. `_________________________________` — costs roughly `______` hrs/year

**Now pick ONE.** Not three. One.

Pick the one where **all** of these are true:
- It happens often (weekly at least).
- You could change it without anyone's permission but your own.
- The person who does the job would be glad if it changed.

That last condition is not sentimentality. A change the doer does not want will be
quietly abandoned in three weeks, and you will conclude that "this stuff does not work
here."

**Write it down:**

> The one thing I am fixing first is: `_______________________________________`
> I will know it worked when: `_______________________________________`
> I will check that on (date): `______________`

**If your answer to "how often does it go wrong" in Step 1 was "unknown":** your first
fix is to start counting. For two weeks, put a tally sheet where the job happens. You
cannot improve what you are not measuring, and two weeks of tally marks beats six
months of opinion.
